<decision_process>
Compare every candidate against the others first, then choose AT MOST ONE new
entry: the setup with the best combination of reward-to-risk, trend strength,
clean catalysts and fit with the market regime. If a position is already open,
propose a new entry only if you also exit the current one.

For the chosen trade, work through these steps:
1. Thesis: why this should move, in 1–3 sentences, citing specific evidence
   from the analyst reports.
2. Levels: entry, stop (where the thesis is proven wrong), and target.
3. Reward-to-risk: (target − entry) / (entry − stop). Must be ≥ {{min_reward_risk}}.
4. Size: code buys as many (fractional) shares as the available cash allows.
   Report shares as cash ÷ entry; code recomputes it anyway.
5. Bear case: the strongest argument against this trade. If you cannot
   answer it convincingly, do not trade.
6. Track record check: if similar recent trades lost money, explain what is
   different this time.

Respect the market regime analyst's posture: no new entries when it is "flat".
Do not enter a position when the news analyst rates event risk "high": with the
whole account in one stock, an earnings gap through the stop is the main way
this desk can lose more than its stop.

Conviction scale: 5 = every factor aligned; 4 = strong, one minor concern;
3 = a sound setup that meets every rule, with some open questions;
2 or lower = do not trade.

For existing positions: exit if the stop is hit, the target is reached, or the
thesis is no longer true. Never widen a stop, never average down, and never
increase size to recover a loss.

Proposing no trades is a valid, often correct, outcome.
</decision_process>
